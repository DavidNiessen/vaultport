# Keyboard shortcuts

<kbd>Mod</kbd> is <kbd>⌘ Command</kbd> on macOS and iPadOS and <kbd>Ctrl</kbd> on Windows, Linux and Android. The shortcuts are also listed in **Settings → Shortcuts**.

## App

| Action              | Shortcut                                        |
| ------------------- | ----------------------------------------------- |
| Command palette     | <kbd>Mod</kbd>+<kbd>K</kbd>                     |
| New tab             | <kbd>Mod</kbd>+<kbd>T</kbd>                     |
| Jump to tab or host | <kbd>Mod</kbd>+<kbd>J</kbd>                     |
| Local terminal      | <kbd>Mod</kbd>+<kbd>L</kbd>                     |
| Close tab           | <kbd>Mod</kbd>+<kbd>Shift</kbd>+<kbd>W</kbd>    |
| Next tab            | <kbd>Ctrl</kbd>+<kbd>Tab</kbd>                  |
| Previous tab        | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Tab</kbd> |
| Settings            | <kbd>Mod</kbd>+<kbd>,</kbd>                     |
| Lock vault          | <kbd>Mod</kbd>+<kbd>Shift</kbd>+<kbd>L</kbd>    |

## Terminal

| Action             | Shortcut                                                                             |
| ------------------ | ------------------------------------------------------------------------------------ |
| Search in terminal | <kbd>Mod</kbd>+<kbd>Shift</kbd>+<kbd>F</kbd>                                         |
| Toggle side panel  | <kbd>Mod</kbd>+<kbd>.</kbd>                                                          |
| Copy selection     | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>C</kbd>, or <kbd>⌘</kbd>+<kbd>C</kbd> on macOS |

Plain <kbd>Ctrl</kbd>+<kbd>C</kbd> is always sent to the remote program (to interrupt it), which is why copying uses <kbd>Shift</kbd> outside macOS. You can also enable **Copy on select** and **Right-click to paste** in **Settings → Terminal**. On macOS, **Use Option as Meta key** (on by default) sends <kbd>⌥ Option</kbd> combinations as Meta/Alt to the shell.

## Workspaces

| Action               | Shortcut                                     |
| -------------------- | -------------------------------------------- |
| Toggle broadcast     | <kbd>Mod</kbd>+<kbd>Shift</kbd>+<kbd>B</kbd> |
| Toggle split / focus | <kbd>Mod</kbd>+<kbd>Shift</kbd>+<kbd>M</kbd> |

## Mouse and touch

- **Middle-click** a tab to close it; **drag** tabs to reorder them.
- **Double-click** the title bar to maximize or restore the window.
- **Double-click** a port-forwarding rule to start or stop it.
- <kbd>Mod</kbd>+click a link in the terminal to open it (you are asked first).
